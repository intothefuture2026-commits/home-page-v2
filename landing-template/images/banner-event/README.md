# 이벤트 배너 (상품권 증정 EVENT)

이 폴더에 이미지 파일 **1개**만 넣으면, 히어로 하단 / 단지개요-위치 사이 / FAQ 앞 이렇게 **3곳에 자동으로 같은 이미지가 반복 표시**됩니다.

## 넣어야 할 파일

| 필요한 파일명 (정확히 일치해야 함) | 어떤 이미지 |
| --- | --- |
| `event-banner.webp` | "본 홈페이지에서 방문예약 후, 상담완료시 상품권 증정 EVENT / 선착순 10팀" 배너 (남색+적색, 만원권 3장 리본 이미지) |

- 갖고 계신 `.webp` 파일 그대로 저장하면 됩니다 (별도 변환 불필요)
- 파일 용량은 **500KB 이하** 권장 (모바일 로딩 속도 때문)
